# Roadmap posterior al release comprometido

Este archivo documenta posibilidades; **no inicia ni compromete alcance Avanzado o Experto**. La
prioridad actual termina al aceptar los niveles Esencial y Medio.

## Nivel Avanzado — backlog

- Evaluar filtros adicionales solo si una prueba con directivos demuestra una necesidad clara.
- Diseñar escenarios de actualización y distribución; cualquier publicación deberá revisar
  licencia, privacidad, costes y gobierno.
- Repetir hipótesis con snapshots fechados o datos internos de reservas antes de hablar de demanda,
  ocupación o conversión.

## Nivel Experto — backlog

- Comparar clustering interpretable con la segmentación de reglas actual y medir estabilidad.
- Evaluar modelos clásicos predictivos únicamente cuando exista una variable objetivo válida y
  separación temporal; evitar predecir reservas a partir de reseñas como si fueran equivalentes.
- Integrar datos demográficos o económicos con licencia, fecha, granularidad y cobertura auditadas.
- Diseñar despliegue público solo después de threat modeling, revisión de privacidad, presupuesto,
  accesibilidad y una estrategia de actualización.

## Condiciones de entrada

Cada iniciativa requerirá especificación propia, decisión de negocio, fuente autorizada, criterio
de aceptación, issue, rama y PR. Ninguna debe degradar la reproducibilidad ni reescribir las
limitaciones del release actual.
